**Nusa Data** — Indonesia's population, economy and society in figures, 1960 to 2025. Twenty-five World Bank indicators across six sections, every number carrying its series ID and the year it was reported. No backend, no build step, no network call: static files, hand-drawn SVG charts.

## Run it

```sh
node serve.ts          # then open http://localhost:8080
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
